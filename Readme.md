
# Student Management System — Java Console Application

A Java-based console application designed to practice and strengthen Core Java concepts, object-oriented programming (OOP), Collections, Java Streams, exception handling, and user input management.

The Student Management System allows users to register students, enroll them in multiple courses, search for students using their student ID, display student records, and sort students alphabetically by name.

## Features

- **Student Registration:** Register new students with their name, age, and unique student ID.

- **Course Enrollment:** Enroll students in multiple courses.

- **Student Search:** Search for a student using their student ID.

- **Display Student Records:** View all registered students and their details.

- **Sorting:** Sort student records alphabetically by name using Comparator and Collections.sort().

- **Interactive Console Menu:** Navigate through application features using a menu-driven interface.

- **Input Handling:** Accept and process user input through Java's Scanner class.

## Technologies Used

## Application Workflow


When the application starts, it displays a menu with the following options:

```bash
-----------------------------------------------------
        Welcome to the Student Management System!
-----------------------------------------------------
`
1. Register a Student.
2. Find Student with Student ID.
3. List All Student Information.
4. List Student Information in Sorted Order.
5. Exit.
```
